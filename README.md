# Zixel Chords Local

เอกสารสถาปัตยกรรมและแผนยกระดับไปสู่ Local AI Music Workstation อยู่ที่ [ARCHITECTURE.md](./ARCHITECTURE.md)

เว็บฝึกเล่นเพลงจากไฟล์ MP3 บนเครื่อง: วิเคราะห์คอร์ดและจังหวะด้วยโมเดลเพลงจริง จัดคอร์ดลง beat grid แล้วให้ฟังทวน แก้ไข ลูปช่วง และส่งออกได้

## เริ่มใช้งาน

1. ดับเบิลคลิก install-ai-engine.cmd หนึ่งครั้ง (ต้องมีอินเทอร์เน็ตเพื่อลงตัวเอนจิน)
2. ดับเบิลคลิก start-zixelchords.cmd (หรือ start-chordtube.cmd)
3. เปิด http://127.0.0.1:4173/
4. เลือก MP3 ที่คุณมีสิทธิ์ใช้ ติ๊กยอมรับเงื่อนไข แล้วกดวิเคราะห์

หน้าสถานะด้านบนจะเป็น “Local AI engine พร้อมใช้งาน” เมื่อติดตั้งสำเร็จ การวิเคราะห์เพลงครั้งแรกอาจใช้เวลานานกว่าเดิมเล็กน้อย เพราะเอนจินดาวน์โหลดน้ำหนักโมเดลที่จำเป็นแบบอัตโนมัติ

## สิ่งที่มีในแอป

- AI chord recognition แบบ Transformer พร้อม beat/downbeat tracking
- ตารางคอร์ดตามจังหวะ, เล่นช้า 0.5× / 0.75×, และลูป A–B
- เครื่องมือเปลี่ยนคีย์, แสดงรูปแบบคอร์ดอ้างอิง, คัดลอก และดาวน์โหลดผลลัพธ์
- โหมดตรวจแก้คอร์ดทีละ beat โดยเก็บ “ร่างจาก AI” ไว้ให้คืนค่าได้
- MP3 ถูกส่งเฉพาะไปยัง localhost; ไฟล์ชั่วคราวในเอนจินถูกลบทันทีหลังประมวลผล

## ขอบเขตและความน่าเชื่อถือ

ผลลัพธ์เป็น AI draft ที่ดีกว่าการเดาคอร์ดจากเบราว์เซอร์ แต่ไม่มีระบบใดรับประกันความถูกต้อง 95% หรือ 100% สำหรับทุกเพลงได้อย่างซื่อสัตย์ โดยเฉพาะเพลงที่มีคอร์ดกลับเสียง, เมโลดีกลบเสียงประสาน, modulation หรือการมิกซ์ซับซ้อน จึงมีโหมดตรวจแก้สำหรับฟังเทียบก่อนใช้งานจริง

ใช้ MP3 ที่คุณมีสิทธิ์ใช้เท่านั้น YouTube ในหน้าเว็บรองรับเฉพาะการเปิดวิดีโอประกอบ ไม่ได้ดาวน์โหลดหรือแยกเสียงจาก YouTube

น้ำหนักโมเดลคอร์ด BTC ที่เอนจินใช้งานเป็น CC BY-NC-SA 4.0 ดังนั้นชุดนี้สำหรับการใช้ส่วนตัวและไม่เชิงพาณิชย์เท่านั้น หากจะให้บริการเชิงพาณิชย์ ต้องเปลี่ยนไปใช้โมเดลหรือ API ที่มีสิทธิ์เหมาะสมก่อน
